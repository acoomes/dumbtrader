# Playbook v0 — Systematic Equity Swing

> The $230 is never going to make me rich. This account is a **unit-test
> harness** for a portable decision policy. Score the loop, not the P&L.

This is the "weights" of the loop: a versioned, plain-text, falsifiable policy.
v0 is deliberately dumb — that is the point. A vibe-based policy can't be
improved, because when it loses you can't tell why. Every change to this file is
a git diff gated by evidence (see `gate.min_decisions`).

## Strategy seed: (a) systematic equity swing

Equities only (cash account, no options level). Fractional shares.

### The three rules (one entry, one sizing, one exit)

1. **Entry (one condition).** On the weekly decision day, among the universe,
   consider only names whose **price > 20-week SMA** (trend filter). Of those,
   take the single name with the **highest 12-week return**, and only if that
   return is **> 0**. If none qualify → **HOLD** (cash is a position).

2. **Sizing (one rule).** Risk **≤ 8% of account equity** per position. With an
   assumed **10% stop**, that caps notional at `0.08 × equity / 0.10`. With
   `max_positions = 1`, the equal-weight ceiling is the whole account, so the
   risk rule binds. Fractional shares.

3. **Exit (one rule).** Close when the weekly close is **below the 20-week SMA**
   (trend broken) **OR** price hits a **−10% stop** from entry — whichever comes
   first. Re-evaluate weekly; no intraweek churn (T+1 settlement on a cash
   account makes daily trading settlement-violation roulette).

### Benchmark (the brutal part)

Buy-and-hold **SPY** with the same capital over the same window. If the loop
can't beat buy-it-and-go-snowboarding, it's a hobby, not an edge — and that's
fine for a learning harness, but it gets named honestly in every reflection.

### Guardrails (keep the harness alive)

- **Sample-size gate.** No rewrite of any rule above without ≥ 20 closed
  decisions of pre-registered evidence (or a stat-sig threshold). A loop that
  "learns" from 5 trades is overfitting with confidence.
- **Position sizing for survival.** ≤ 8% risk/trade so a losing streak can't
  zero the testbed before the loop learns anything.
- **Adherence logging.** Every override is recorded. The reflection scores the
  policy *as actually run*, not the policy on paper.
- **Regime tagging.** Every lesson is stamped with the market regime it was
  learned in. A melt-up lesson is a liability in a chop.
- **Kill switch.** At −30% account drawdown, halt and do a full review instead
  of tweaking.

## How v0 runs

Weekly ritual (mirrors Morning Download):

1. Pull account state + positions + quotes (Robinhood tools).
2. Score the prior week against the **frozen** objective.
3. Reflect (optionally through the consensus panel) — grade decisions, not
   results.
4. Propose a playbook diff (only if the gate clears) + any trades.
5. **I propose, you confirm — every single order.** No auto-firing path.
6. Execute confirmed orders; commit the new playbook version.

Metrics land in the Notion "Agentic Loop" DB (schema in
`agentic/docs/NOTION_SCHEMA.md`); the playbook + iteration logs live here in git
(and copy straight into the Obsidian vault).
